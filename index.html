The ritual

Five beats. One shared moment.

Every step gives chat one short, clear job and pays it off on stream. Graphics live in a side panel and a lower third, so the game stays visible.

01

Summon

Viewers type !lore. Each witness locks onto the summoning circle.

02

Name it

LORE auto-clips the moment and drafts three titles. Chat votes 1 2 3.

03

Canonize

A collectible card reveal. The more of chat that joins, the rarer the card.

04

Initiate

A newcomer asks what the joke means. LORE explains it with the clip.

05

Lore Trials

A quiz built from the channel's own history. Fastest answers become Loremasters.

Participation is rarity

Chat is rewarded for showing up together.

Every summoner and voter is printed on the card as a witness. Bigger crowds mint rarer lore.

Add LORE to OBS in a minute

  1. Run npm install, npm run seed, npm start.
  2. Add a Browser Source at 1920 x 1080.
  3. Paste the overlay URL and go live.
